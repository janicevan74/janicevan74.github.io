# MiniatureNestStudio

Tips and guides for dollhouse miniatures, in English and Spanish.

Live site: https://miniatureneststudio.com

## Editing

`_src/source.html` is the master copy of all content (both languages in one file).
After editing it, run `python3 _src/build.py` from the repo root to regenerate the
English and Spanish pages, `assets/`, `sitemap.xml` and `404.html`, then commit.
Folders starting with `_` are not published by GitHub Pages.
